# 隐私与版权

这个仓库从一次真实采访项目里提炼而来。上传前做了两件事：**排除原始素材**、**改写代码里的个人信息**。

## 一、没有上传的东西

| 内容 | 原位置 | 不上传的原因 |
|---|---|---|
| 采访原声 `*.wav` | `01-素材/` | 可识别的声音，属于个人信息 |
| 原始视频 / 出镜片段 | `01-素材/`、`public/clips/` | 人脸 + 声音 |
| 逐字稿、分段、词级时间戳 | `01-素材/转写/` | 包含完整谈话内容、家庭与收入信息 |
| 成片 `*.mp4` | `03-成片/` | 人脸 + 声音 + 全部内容 |
| 关键帧、QA 截图 | `03-工程/qa*/`、`stills/` | 画面里有人脸和真实数据 |
| 真实分镜 `scenes.py`、选段表 | `03-工程/`、`02-脚本/` | 含学校、专业、收入、家庭细节 |
| 第三方向导仓库 | `工具/xiaolin-explainer-packaging` | 100MB，且许可证未明确 |

`.gitignore` 里对上述类型做了兜底，防止以后误提交。

## 二、代码里的脱敏

- 人名 / 网名 → `小 A`
- 学校 → `某大学`
- 专业 → `工科专业`
- 收入、成本、目标 → 示例数字（1500/3000/200），并标注「示例值」
- 所有绝对路径（`E:\...`）→ 命令行参数或相对路径
- 删除了原始项目里的临时脚本（`_pip*.py`、`_face*.py` 等），它们只为处理这一期素材存在

## 三、发布前自检

在仓库根目录跑：

```bash
# 1. 看有没有真实姓名 / 学校 / 手机号 / 微信
rg -n "姓名|学校|专业|手机号|微信号|学号|身份证" .
# 再把本期出现的人名、校名、机构名逐个补进正则跑一遍

# 2. 看有没有绝对路径
rg -n "[A-Z]:\\\\|/Users/|/home/" .

# 3. 看有没有媒体文件被跟踪
git ls-files | rg "\\.(wav|mp3|mp4|mov|png|jpg)$"

# 4. 看仓库体积
git count-objects -vH
```

第 3 条应该没有输出；第 4 条的 `size-pack` 应在几 MB 以内。

## 四、仓库可见性

本仓库默认 **Private**。确认上面四条都干净、并且确实想公开时，再在
GitHub → Settings → General → Danger Zone → Change visibility 改为 Public。

公开前再想一遍：分镜里的数字即使改成示例，叙事结构仍然对应真实受访者。
如果对方不希望被认出，建议保持 Private。

## 五、第三方代码与许可证

- **Remotion**：个人、3 人以内公司、非营利组织可免费商用；4 人以上公司需要购买授权。
  见 https://www.remotion.pro/license
- **分镜引擎**（`story_core.py` 与 `src/` 下的组件）：改编自
  [howoneai/xiaolin-explainer-packaging](https://github.com/howoneai/xiaolin-explainer-packaging)。
  该仓库未声明标准开源许可证，因此本仓库按「个人学习与备份」使用，不再对外分发。
- **字体**：引擎默认使用思源黑体等 SIL OFL 字体，字体文件不随仓库分发；
  优设标题黑需自行从官方渠道下载。
- **音乐 / 音效 / 截图 / Logo**：均需自行确认授权，仓库不附带。

## 六、如果误传了

1. 立刻把仓库改为 Private。
2. 删除对应文件并 `git commit`，但历史里仍有，需要
   `git filter-repo --path <文件> --invert-paths` 重写历史后强推。
3. 已经公开过的内容可能被 fork / 缓存，必要时联系 GitHub Support 清理。
