# 流程细节

## 0. 两条轨

| 轨 | 内容 | 在哪 |
|---|---|---|
| A-roll | 受访者出镜口播，一句一个片段 | `public/clips/*.mp4` |
| 包装层 | 标题卡、数字、图表、流程图、字幕、转场、音效 | Remotion 组件 |

包装层不碰人脸，只按时间戳叠在 A-roll 上。人物画面默认做右下角画中画（PiP），需要时全屏。

## 1. 素材

- 原声：`ffmpeg -i camera.mov -vn -ac 1 -ar 16000 work/source.wav`
- 出镜：1920×1080、**24fps**、H.264；和合成帧率不一致会出现重复帧。
- 每句一个片段最省事；也可以一整段 + `tin/tout` 切。

## 2. 转写

`faster-whisper medium + int8` 在 8 核 CPU 上大约是 1 分钟音频跑 20-30 秒，准确率够做时间轴。

关键参数：

- `vad_filter=True`：先去掉静音，避免整段偏移。
- `condition_on_previous_text=False`：长音频不会越写越跑偏。
- `initial_prompt` 给一个中文语境，减少繁体输出。

长段（>12 秒）在 whisper 里容易吞句，`refine_long.py` 会把长段切出来重新转一次再合并。

## 3. 断句与切片

1. `make_sentences.py`：按句末标点和 >0.9 秒停顿合并成句。
2. `build_units.py`：把句子切成 14-26 字的口播单元。
   - 上限 26 字：一行字幕放得下，也方便选段。
   - 下限 14 字 / 2.2 秒：避免切出「对」「然后」这种碎片。
3. `dump_segments.py`：导出 `s001 12.30-15.80 文本`，方便通读。

## 4. 选段

选段表按「段落（beat）」组织，常见段落：

```
hook → who → origin → cost → income → track → moat → edge → auto
→ repurchase → costtime → traffic → low → now → future → teach
→ goal → ordinary → study → quick → account → close
```

每个 beat 对应 1-3 个场景。选段时顺手把字幕写好（`sub`），分镜里直接用。

裁剪参数 `tin/tout` 是首尾各切掉多少秒，用来掐掉呼吸声和口头语。

## 5. 时间轴格式

`timeline.json` 是数组，元素两种：

```json
{"id": "S01", "kind": "clip", "src": "clips/source.mp4", "tin": 1.62, "tout": 6.0,
 "say": "口播原文", "sub": "字幕文字"}
```

```json
{"id": "TITLE", "kind": "card", "dur": 3.6}
```

`story_core.py` 会按顺序累加 `start`，不用手写时间。

## 6. 分镜 API

```python
T = G('S03')            # 取某一段
t0, t1 = T.t0, T.t1     # 绝对起止秒
T.k('零成本')            # 「零成本」被说出的绝对秒数（按字位插值）
T.at(0.5)               # 段内 50% 位置

sc = Scene('cost', t0, {'type': 'dark', 'particles': True})
sc.add('bignum', t0 + 0.02, v='200', unit='块', kicker='启动成本', sfx='kaching')
sc.cam(t0, x=930, y=500, s=1.12)
show(sc, t0, t1, aroll='pip', pip='br')
```

常用组件：`titlecard` `endcard` `wall` `bignum` `paper` `flow6` `vs6` `tree6`
`tag` `doc` `webshot` `photo` `panel`。

## 7. 编译

```bash
cd remotion
python story_core.py ../work/timeline.json ../scenes.py
```

产物：

| 文件 | 用途 |
|---|---|
| `src/data/shots.json` | Remotion 的唯一输入 |
| `sfx.json` | `[[秒, 音效名], ...]`，混音用 |
| `keyframes.json` | `[[场景名, 帧号], ...]`，抽帧检查用 |

编译时会自动：

- 给没被场景覆盖的口播补全屏 A-roll（交替 1.0/1.13 倍推近）。
- 按场景类型分配转场（zoom / whip / flash / glitch / cut）。
- 把文档、图表、照片改成 3D 飞入。

## 8. 渲染

```bash
node render.mjs stills out/stills 120 360 600   # 抽帧
node render.mjs video out/video.mp4 0 9999 6    # 全片，6 并发
```

分段渲染时 `frameRange` 用 `[a, b]`，最后 ffmpeg concat。

## 9. 混音

```bash
# 人声标准化
ffmpeg -i work/source.wav -af loudnorm=I=-19.5:TP=-1.5:LRA=11 work/voice.wav

# 音乐垫底（约 -33 LUFS），淡入淡出
ffmpeg -i bed.mp3 -af "volume=0.12,afade=t=in:d=1.2,afade=t=out:st=END:d=6" work/bed.wav

# 三段相加
ffmpeg -i voice.wav -i bed.wav -i sfx.wav -filter_complex amix=inputs=3:duration=longest work/mix.wav
```

音效时间点直接读 `sfx.json`，按 24fps 对齐到帧。

## 10. 质检

1. 抽 10-20 个关键帧（`keyframes.json`），看字幕压边、数字遮挡、PiP 挡脸。
2. 全片 1.0 倍速回放一遍，重点听：气口、音效是否抢话、音乐是否盖人声。
3. 用 `ffprobe` 确认分辨率 / 帧率 / 时长 / 音轨。
